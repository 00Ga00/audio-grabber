Audio Studio 3.1 使用说明
=========================

【第一次使用】
1. 安装 Python 3.10 或更高版本：
   https://www.python.org/downloads/
   安装时请勾选“Add python.exe to PATH”。
2. 下载并解压整个项目文件夹。
3. 双击 start.bat。第一次会自动创建独立环境并安装组件，可能需要几分钟。
4. 以后继续双击 start.bat 即可快速打开。

【基本使用】
1. 复制视频链接，在窗口里点“粘贴”。
2. 选择保存位置、输出格式和音质。
3. 点“开始提取”。完成后可点“打开文件位置”。

格式建议：
- mp3：兼容性最好，适合一般播放设备。
- m4a：音质和文件大小平衡较好。
- opus：文件较小，部分旧设备不支持。
- flac / wav：文件很大；从有损网站音频转换并不会恢复已经损失的音质。
- 原始格式：不重新编码，速度快，也避免再次压缩；扩展名取决于网站。

【只保存一段】
勾选“只保存一段”，填写开始或结束时间。支持：
- 1:30（1 分 30 秒）
- 90（90 秒）
- 1:02:03（1 小时 2 分 3 秒）
结束时间留空表示一直保存到结尾。

【需要登录的内容】
- Firefox：通常最稳定。先在 Firefox 登录网站，再在工具中选择 Firefox。
- Edge / Chrome：读取失败时，先完全关闭浏览器再试。
- cookies.txt：在你信任的浏览器扩展中导出，然后在工具中选择该文件。

cookies.txt 等同于登录凭证，不要发送给别人，也不要上传到 GitHub。
工具不会记住 cookies.txt 的文件路径。

【常见问题】
- 链接突然无法解析：双击 update.bat 更新组件。
- 安装失败：检查网络，再运行 start.bat。
- 任务失败：点“复制日志”，保留错误信息以便排查。
- 分P视频：链接带 ?p=3 时会处理第 3P；不带时通常处理第 1P。

请只下载你有权保存的内容，并遵守网站服务条款和版权法律。

【电脑录音】
1. 打开“电脑录音”页（录音组件在第一次运行 start.bat 时已自动准备好）。
2. 选择“全部电脑声音”，或选择“只录一个程序”并在列表中选择浏览器等程序；
   “除了一个程序都录”可以把某个程序（例如聊天软件）排除在外。
3. 选择 WAV / FLAC / MP3 / M4A / Opus。
4. 可启用定时停止、静音自动停止、去首尾静音、静音分段和音量标准化。
5. 点击“开始录音”。录音期间可暂停、继续或停止。

全局快捷键：
- Ctrl + Alt + R：开始 / 停止
- Ctrl + Alt + P：暂停 / 继续

单程序录音使用 Windows 进程环回接口，要求 Windows 10 2004 或更新版本。
目标浏览器的子进程也会一起录制；其他程序和系统提示音不会混入。

【音质增强】
- AI 人声增强：适合课程录音、访谈、会议等语音；AI 组件在第一次运行 start.bat 时自动下载。
  降噪强度选“轻”会保留一点环境声，听起来更自然；“强”去噪最彻底。
- 清晰增强（传统）：安装体积小，适合轻度底噪和音量不一致。
- AI 模型不会让低码率音乐真正恢复成无损音质，也可能改变音乐质感。
