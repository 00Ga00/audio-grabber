# Audio Studio

一个面向 Windows 的本地音频工具：从视频提取音频、演唱会视频 AI 降噪、录制电脑声音，以及增强已有音频。
底层使用 [yt-dlp](https://github.com/yt-dlp/yt-dlp)、ffmpeg、Windows WASAPI 和可选的 DeepFilterNet3。

## 功能

- 支持 B站、YouTube，以及 yt-dlp 支持的其他网站
- 输出 mp3、m4a、flac、wav、opus，或直接保存原始音频
- 三档音质；可按开始和结束时间截取片段
- 可读取 Firefox、Edge、Chrome 登录状态，也可选择 cookies.txt
- 显示下载进度，支持取消任务、复制错误日志、打开生成文件
- 自动记住保存位置、格式和音质（不会保存 cookies 文件路径）
- 自动移除常见分享链接跟踪参数，输出文件只写入必要的标题和作者信息
- 使用独立的 Python 环境，不污染电脑上已有的 Python 软件包

### 电脑录音

- WASAPI 数字环回录音，可录制全部电脑声音
- Windows 10 2004 及以上可只录指定程序及其子进程，例如只录浏览器
- 暂停/继续、定时停止、静音自动停止
- 全局快捷键：`Ctrl+Alt+R` 开始/停止，`Ctrl+Alt+P` 暂停/继续
- 自动去掉首尾静音、按静音分段、响度标准化
- 输出 WAV、FLAC、MP3、M4A 或 Opus

- 还可以“除了一个程序都录”，例如录游戏声音但不录聊天软件

录音组件的源码在 `recorder-helper/`，第一次运行时用 Windows 自带的 .NET Framework 编译器
在本机编译，不需要下载任何程序；采用微软的进程环回接口，不会通过麦克风录制。

### 演唱会降噪

- 从现场视频（mp4、mkv、mov……）或音频里取出声音，用音乐专用的 Mel-Band RoFormer 模型处理：
  - 去观众声：去掉尖叫、鼓掌、欢呼（aufr33 & viperx 的 crowd 模型）
  - 去底噪：去掉嘶嘶声、风声、电流声（aufr33 的 denoise 模型）
  - 音质修复：补回被压缩砍掉的高音、减轻压缩失真，适合手机录的或从社交软件存下来的视频
    （[Apollo](https://github.com/JusperLee/Apollo) 音乐修复模型的 Universal 版本，约 140 MB，第一次使用时自动下载）
- 先试听 30 秒（原声 / 调整后对比），满意再处理整段
- 可以自己调：降噪强度、自动音色校正、低频、中频、高频、补回的高音；AI 只跑一次，
  拖动滑块后试听和重新导出都只要几秒；常用设置可以按歌手存成预设
- 频谱图实时显示原声、调整后和均衡曲线，还会标出压缩截止频率
- 自动音色校正：把手机录音的长期频谱往优秀现场录音的平均音色靠（低频不轰、中频更清楚），
  校正量有上限；6 kHz 以上最多只提 3 dB，避免放大压缩失真
- 音质修复只补截止频率以上原本空白的部分，原有的声音一点都不改
- 输出 24-bit FLAC，可同时生成降噪后的视频（画面直接复制，不重新压缩）
- 不做压缩、限幅和均衡，音乐本身不被改动；长音频分段处理、段间无缝衔接
- 单声道的手机录音会原样放进左右声道，音量不变
- 有 NVIDIA 显卡时自动使用显卡加速（安装时会确认 PyTorch 真的能用上显卡）
- 第一次使用在程序里点“安装演唱会降噪组件”（约 4 GB，装在独立环境 `.venv-ai`）

### 音质增强

- “AI 人声增强”使用 DeepFilterNet3 官方独立程序（约 26 MB，模型内置，不需要 PyTorch），
  适合语音降噪和清晰度提升，可选降噪强度
- “清晰增强（传统）”无需安装 AI 模型，使用滤波、频谱降噪和响度标准化
- AI 模型不会恢复原文件中不存在的细节，也不建议用于音乐母带
- 第一次运行 start.bat 时自动下载 AI 组件；模型和音频都在本机处理

## 快速开始（Windows）

1. 下载本仓库（Code → Download ZIP），右键“全部解压缩”。
2. 双击 `start.bat`。

第一次运行会自动完成全部准备：没有 Python 时尝试用 winget 自动安装、创建独立环境、
安装 yt-dlp 和 ffmpeg、编译录音组件、下载 AI 组件，需要联网几分钟。
完成后桌面上会出现 **Audio Studio** 图标，以后双击它就直接打开（没有黑色窗口）。

如果网站更新后突然无法解析，双击 `update.bat` 更新组件，再重试。

更详细的中文说明见 [USAGE_zh.txt](USAGE_zh.txt)。

## 隐私与安全

- `cookies.txt` 相当于登录凭证，请勿发送给别人或提交到 GitHub。
- 本项目的 `.gitignore` 已排除常见 cookies 文件和下载的音频。
- 浏览器登录信息只由本机上的 yt-dlp 在任务期间读取，本工具不会上传或保存它。
