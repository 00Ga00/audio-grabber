# Audio Studio

一个面向 Windows 的本地音频工具：从视频提取音频、演唱会视频 AI 降噪、录制电脑声音，以及增强已有音频。
底层使用 [yt-dlp](https://github.com/yt-dlp/yt-dlp)、ffmpeg、Windows WASAPI 和可选的 DeepFilterNet3。

## 功能

左侧导航按功能分区：视频提取、演唱会降噪、扒谱、电脑录音、音质增强；所有 AI 组件安装、语言和更新集中在左下角“设置”。


- 支持 B站、YouTube，以及 yt-dlp 支持的其他网站
- 输出 mp3、m4a、flac、wav、opus，或直接保存原始音频
- 三档音质；可按开始和结束时间截取片段
- 可读取 Firefox、Edge、Chrome 登录状态，也可选择 cookies.txt
- 显示下载进度，支持取消任务、复制错误日志、打开生成文件
- 自动记住保存位置、格式和音质（不会保存 cookies 文件路径）
- 自动移除常见分享链接跟踪参数，输出文件只写入必要的标题和作者信息
- 使用独立的 Python 环境，不污染电脑上已有的 Python 软件包

### 电脑录音

- WASAPI 数字环回录音，可录制全部电脑声音
- Windows 10 2004 及以上可只录指定程序及其子进程，例如只录浏览器
- 暂停/继续、定时停止、静音自动停止
- 全局快捷键：`Ctrl+Alt+R` 开始/停止，`Ctrl+Alt+P` 暂停/继续
- 自动去掉首尾静音、按静音分段、响度标准化
- 输出 WAV、FLAC、MP3、M4A 或 Opus

- 还可以“除了一个程序都录”，例如录游戏声音但不录聊天软件

录音组件的源码在 `recorder-helper/`，第一次运行时用 Windows 自带的 .NET Framework 编译器
在本机编译，不需要下载任何程序；采用微软的进程环回接口，不会通过麦克风录制。

### 演唱会降噪

- 从现场视频（mp4、mkv、mov……）或音频里取出声音，用音乐专用的 Mel-Band RoFormer 模型处理：
  - 去观众声：去掉尖叫、鼓掌、欢呼（aufr33 & viperx 的 crowd 模型）
  - 去底噪：去掉嘶嘶声、风声、电流声（aufr33 的 denoise 模型）
  - 音质修复：补回被压缩砍掉的高音、减轻压缩失真，适合手机录的或从社交软件存下来的视频
    （[Apollo](https://github.com/JusperLee/Apollo) 音乐修复模型的 Universal 版本，约 140 MB，第一次使用时自动下载）
- 先试听 30 秒（原声 / 调整后对比），满意再处理整段
- 可以自己调：降噪强度、自动音色校正、低频、中频、高频、补回的高音；AI 只跑一次，
  拖动滑块后试听和重新导出都只要几秒；常用设置可以按歌手存成预设
- 频谱图实时显示原声、调整后和均衡曲线，还会标出压缩截止频率
- 自动音色校正：把手机录音的长期频谱往优秀现场录音的平均音色靠（低频不轰、中频更清楚），
  校正量有上限；6 kHz 以上最多只提 3 dB，避免放大压缩失真
- 音质修复只补截止频率以上原本空白的部分，原有的声音一点都不改
- 人声/伴奏分开调：伴奏 = 处理后 − 人声，默认设置下与不分离逐点一致；伴奏可单独调音量、低频、刺耳频段、高频，
  以及“动态柔化”（只在特别刺耳的时刻压 2–5 kHz，其他时候不动）；可另存人声、伴奏分轨
- 导出的响度默认和原视频一致（需要时最多 4 dB 前瞻限幅，不削波），也可统一到 -14 LUFS 或不调整
- 时间轴显示每秒的响度、刺耳度（处理后还有人声），点一下就从那里试听；“按住=听原声”在同一时间点对比
- 批量处理多个视频、可随时取消；视频可直接拖进窗口；“视频提取”下载完可直接送来降噪
- 进度细到模型内部每一小块；模型下载显示 MB 进度，断了不会留下损坏的文件
- 显卡半精度加速（可在“设置”页关闭），中间文件的位置也可在“设置”页里改到空间大的硬盘
- 参考曲音色匹配：选同一首歌的录音室版，自动音色校正就照着它的音色来
- 空间：伪立体声宽度（单声道播放时完全抵消，不会变味）、现场感（去混响 ↔ 加音乐厅空间感）、耳机空间音频
- 显示歌曲调性和速度（现场录音仅供参考）

### 扒谱与声部分析

- 用 [MuScriptor](https://github.com/muscriptor/muscriptor)（Kyutai & Mirelo）把录音扒成多乐器 MIDI，再整理成 MusicXML 总谱和分谱；
  装了 MuseScore 会自动导出 PDF。结果是初稿，请在 MuseScore 里校对
- 更准的做法：先去观众声和底噪；用 Beat This! 找节拍和小节线（拍号、速度变化）；知道编制时“指定乐器”；“最准”用大模型 + 束搜索
- 记谱：对齐到节拍网格（16 分音符和三连音，可选到 32 分）、自动调号、钢琴/竖琴分上下谱表、移调乐器自动写成记谱音高、按总谱顺序排列
- 声部音量地图：BS-Roformer SW 六轨分离（人声/鼓/贝斯/吉他/钢琴/其他）后每秒响度，加上扒谱得到的每件乐器演奏时段
- 第一次使用：在左下角“设置”页点“安装扒谱组件”，并在 Hugging Face 同意 MuScriptor 的许可、填入令牌（模型为 CC BY-NC，非商业用途）

### 吉他扒谱（弹唱 / Solo）

- 六轨分离得到吉他、贝斯和伴奏，再做下面几件事：
  - 和弦（弹唱）：按拍识别和弦（大三、小三、七和弦、挂留、减和弦、转位 C/E），每小节列出和弦进行；给出调性，
    并自动建议变调夹位置（换算成最好按的开放和弦指法），配按法图
  - Solo 六线谱：用 MuScriptor 只扒吉他音符，可只保留旋律，对齐到拍子（16 分音符 / 三连音）；
    按左手把位选最顺手的弦和品（尽量不换把、快句更不换把、高把位少用空弦），滑音 / 击弦 / 勾弦一定排在同一根弦上
  - 演奏技巧：用音高曲线识别滑音、推弦（含推弦回放）、击弦 / 勾弦、揉弦，标在六线谱、Guitar Pro、MusicXML 和指板上
- 输出：吉他谱（HTML 和 PDF：和弦按法图 + 和弦进行 + Solo 六线谱 + 每小节一张的静态指板图）、Guitar Pro 文件（.gp5）、五线谱 + 六线谱 MusicXML（装了 MuseScore 时再导出 PDF）、
  伴奏（去掉吉他）和只有吉他的音频
- 程序里的指板：播放时显示现在要按的位置、下一个音，没有 Solo 时显示当前和弦的按法；可放慢到 50%（音高不变）、只听伴奏、循环练习
- 边放边录：直接录电脑正在播放的声音（网页、音乐软件都行），录的时候实时显示当前和弦和按法，停止后自动完整扒谱（和弦 + Solo 六线谱）
- 建议用“只扒一段”只选 Solo 那一段，快很多；AI 识别是初稿，请对照原曲校对

### 其他

- 界面语言：中文 / English / Deutsch（左下角“设置”里切换，重启生效）
- 一键更新：启动时自动检查 GitHub 上有没有新版本，点一下就更新并重启（不动 AI 组件、模型和设置）
- 输出 24-bit FLAC，可同时生成降噪后的视频（画面直接复制，不重新压缩）
- 不做压缩、限幅和均衡，音乐本身不被改动；长音频分段处理、段间无缝衔接
- 单声道的手机录音会原样放进左右声道，音量不变
- 有 NVIDIA 显卡时自动使用显卡加速（安装时会确认 PyTorch 真的能用上显卡）
- 第一次使用在左下角“设置”页安装演唱会降噪组件：先检查电脑配置，再推荐版本，配置低的电脑不下载用不上的大模型
  （精简版：去观众声 + 去底噪；标准版：再加人声分离、音质修复；完整版：再加去混响。约 2–7 GB，装在独立环境 `.venv-ai`）
- 按电脑配置自动分级（高配 / 中配 / 低配）：锁住在这台电脑上太慢的选项、估计处理时间、“按电脑配置推荐”一键选好处理步骤；
  小显存时一次只放一个模型。设置里可以“解除限制”

### 音质增强

- “AI 人声增强”使用 DeepFilterNet3 官方独立程序（约 26 MB，模型内置，不需要 PyTorch），
  适合语音降噪和清晰度提升，可选降噪强度
- “清晰增强（传统）”无需安装 AI 模型，使用滤波、频谱降噪和响度标准化
- AI 模型不会恢复原文件中不存在的细节，也不建议用于音乐母带
- 第一次运行 start.bat 时自动下载 AI 组件；模型和音频都在本机处理

## 快速开始（Windows）

1. 下载本仓库（Code → Download ZIP），右键“全部解压缩”。
2. 双击 `start.bat`。

第一次运行会自动完成全部准备：没有 Python 时尝试用 winget 自动安装、创建独立环境、
安装 yt-dlp 和 ffmpeg、编译录音组件、下载 AI 组件，需要联网几分钟。
完成后桌面上会出现 **Audio Studio** 图标，以后双击它就直接打开（没有黑色窗口）。

如果网站更新后突然无法解析，双击 `update.bat` 更新组件，再重试。

更详细的中文说明见 [USAGE_zh.txt](USAGE_zh.txt)。

## 隐私与安全

- `cookies.txt` 相当于登录凭证，请勿发送给别人或提交到 GitHub。
- 本项目的 `.gitignore` 已排除常见 cookies 文件和下载的音频。
- 浏览器登录信息只由本机上的 yt-dlp 在任务期间读取，本工具不会上传或保存它。
